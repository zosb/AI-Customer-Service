# 业务流程说明

## 1. 用户注册与登录

```mermaid
sequenceDiagram
    participant U as 用户
    participant V as Vue
    participant F as FastAPI
    participant M as MySQL
    U->>V: 邮箱/手机号 + 密码
    V->>F: POST /auth/register 或 /auth/login
    F->>F: 账号格式 / 密码策略 / Argon2
    F->>M: 用户查询或持久化
    F-->>V: User / JWT
```

## 2. 文档上传与向量化

```mermaid
sequenceDiagram
    participant A as 管理员/用户
    participant F as FastAPI
    participant M as MySQL
    participant O as Ollama Embedding
    participant C as Chroma
    A->>F: multipart TXT/MD/PDF
    F->>F: 类型/大小/SHA-256/解析/Chunk
    F->>M: 创建 processing 文档记录
    F->>O: 批量 Embedding
    O-->>F: 1024维向量
    F->>C: upsert vector + text + metadata
    F->>M: 保存 Chunk/vector_id，status=ready
    F-->>A: 文档元数据与状态
```

失败时文档记录进入 `failed` 并保存错误信息，避免前端长期停留在“处理中”。

## 3. 智能问答完整链路

```mermaid
sequenceDiagram
    participant U as 用户
    participant V as Vue
    participant F as FastAPI
    participant M as MySQL
    participant C as Chroma
    participant O as Ollama
    U->>V: 输入问题
    V->>F: POST /chat/sessions/{id}/messages
    F->>F: JWT / 500字 / 每日额度
    F->>M: 最近N轮 + 保存用户消息
    F->>O: Query Embedding
    F->>C: 路由 Probe / 目标知识库检索
    C-->>F: 候选 Chunk
    alt 无可靠证据
        F->>M: 保存 fallback AI 消息
        F-->>V: meta + delta + sources([]) + done
    else 有可靠证据
        F->>F: 去重 / A-B分层 / 上下文预算 / Prompt
        F->>O: Streaming Chat
        loop 模型持续生成
            O-->>F: token/chunk
            F-->>V: SSE delta
        end
        F->>F: 来源清洗 + Evidence Guard
        opt 需要修复或安全替换
            F-->>V: SSE replace
        end
        F->>M: 保存 AI 消息 + message_sources
        F-->>V: sources + done
    end
```

## 4. 反馈流程

1. 用户在 AI 消息上选择“有帮助/没帮助”。
2. 可填写最多 1000 字文字反馈。
3. 后端验证该消息属于当前用户可访问会话。
4. 同一用户对同一消息执行 upsert，避免重复反馈。
5. 管理后台聚合满意率及反馈明细。

## 5. 删除文档

```text
确认文档存在
→ 获取全部 Chunk/vector_id
→ 删除 Chroma 向量
→ 更新/删除 MySQL 关联记录
→ 删除上传文件
→ 返回 vector_data_deleted / disk_file_removed
```

删除知识库时对库下所有文档执行级联清理。

## 6. 多知识库路由

未手动绑定知识库的 Session：

```text
Query Embedding
→ 跨库 Probe
→ 相似度聚合
→ routing_description 业务关键词辅助
→ 选择目标知识库
→ 目标库内最终 Top-K
```

若路由或最终检索不足阈值，宁可安全兜底，也不把多个业务库的规则拼在一起猜答案。
