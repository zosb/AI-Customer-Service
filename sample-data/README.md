# 示例知识数据

本目录提供 3 篇公开、虚构的演示知识文档，用于快速验证 AI 智能客服系统的知识库上传、解析、Chunk 切分、Embedding、Chroma 检索、RAG 回答、知识来源和多轮追问能力。

- `公司产品介绍.txt`
- `常见问题FAQ.md`
- `退换货政策.txt`

三篇示例文档正文合计约 **4511 字符**，处于笔试题建议的 2000–5000 字范围内。

## 使用方式

1. 启动 MySQL、Ollama、后端和前端。
2. 登录系统，进入“知识库管理”。
3. 创建一个知识库，例如“演示知识库”。
4. 将本目录 3 篇文档上传到同一知识库。
5. 文档上传后，系统会自动执行解析、Chunk 切分、`qwen3-embedding:0.6b` 向量化并写入 Chroma。
6. 等待文档状态变为“就绪”后即可开始问答。

> 正式应用启动流程不会强制写入演示数据，避免污染生产知识库；示例数据采用显式导入方式。向量化过程在上传后自动完成。

## 推荐测试问题

- 星河智能耳机 X1 的标准保修期是多久？
- X1 曜石黑版本的内部产品代码是什么？
- 售后客服电话是多少？人工服务时间是什么？
- 购买后 30 天内出现非人为质量问题有什么政策？
- 退款审核通过后通常多久原路退回？
- 单次问题最多可以输入多少字？
- 一个账号每天最多可以提问多少次？
- 星河智能科技创始人毕业于哪所大学？

最后一问在示例知识中没有答案，预期系统应进入标准兜底，不应编造信息。
